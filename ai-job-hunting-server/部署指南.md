

## 配置相关


### application

#### AI相关
- 简历在服务端提取 PDF、DOCX、DOC 文字，不需要 Kimi 文件接口；扫描件需先 OCR，详见 [简历解析](docs/resume-parsing.md)。
- 插件的自有 API 支持 OpenAI Chat Completions 与 Claude / Anthropic Messages 两种格式，可自定义模型和地址；配置方法及数据库增量脚本见 [AI 接口配置](docs/ai-api-formats.md)。


#### 支付相关
- 如果是自用，不需要配置，直接删除相应key即可。
- 如果是部署赚米，在支付宝开放平台获取对应的配置即可

#### smart-config
- 用于动态配置管理页面的用户名和密码
- 后续可通过ip:6768访问配置后台，调整参数

#### 数据库
- 使用 PostgreSQL 16 或更新版本，先创建 UTF-8 数据库 `ai_job`，再以表所属用户执行 `resources/schema.sql`。
- 通过 `DB_URL`、`DB_USERNAME`、`DB_PASSWORD` 配置连接，三项均须由运行环境提供；地址示例为 `jdbc:postgresql://localhost:5432/ai_job`。
- 自动建表已关闭。新库初始化、旧数据迁移注意事项及隔离测试命令见 [PostgreSQL 说明](docs/postgresql.md)。

#### login-Filter.freeLoginArray
-当前配置为免登配置，如果有需要可以新增，尽量不要删减

#### openai.pool.config.list
- ai会话交互所需要的apikey池
- 配置对应的base-url和api-key以及模型名称
